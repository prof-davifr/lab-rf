# Simulação: o openEMS Lab

Esta pasta tem tudo o que vai para a instalação do openEMS Lab. Para instalar, siga o
[README principal](../README.md#1-simular-instalar-o-openems-lab).

| Pasta ou arquivo | O que é |
|---|---|
| `INSTALAR.bat` | instalador do Windows (vai no release) |
| `instalar.sh` | instalador do Linux (vai no release) |
| `pacote/` | arquivos que vão para dentro da instalação: atalhos, scripts e leia-me |
| `emslab/` | pacote Python de apoio: geometria, simulação e gráficos |
| `notebooks/` | notebooks em português, do 00 ao 05 |

Os projetos de [../projetos](../projetos) também vão para a instalação e são copiados para
`Documentos/openEMS-notebooks/projetos`.

Para manter o pacote e publicar uma versão, veja [../docs/manutencao.md](../docs/manutencao.md).
